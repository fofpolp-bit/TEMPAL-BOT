# Tempal — Telegram RP Bot

Полностью автономный Telegram-бот для текстовой РП-игры **Темпал** —
командной игры с временными аномалиями, придуманной Марко Веторио.

Бот ведёт матч сам: открывает лобби, делит игроков на команды (включая
запасных), случайно раздаёт способности, описывает арену эмодзи-картой,
кидает кинематографичные d20-роллы и считает очки.

## Что умеет

- 🕰️ **5 зон арены** (ускорение / замедление / норма / инверсия / хаос) — лор
- 🌀 **Хаотичная зона** меняет под-эффект каждые 1–5 минут
- ⚡ **4 способности** строго по лору: Ускорение, Замедление, Заморозка, Инверсия
- 🎲 **d20-роллы** с тремя исходами: 1–5 неудача, 6–15 частичный, 16–20 полный успех
- ⚔️ **Атака** — кидаешь d20 против ролла цели, выше = срываешь её ход (как захват флага)
- 🪑 **Запасные игроки** — резерв на случай, если кто-то выбудет
- 🎬 **Кинематографичные d20** — анимированный прогресс-бар вместо «выпало 14»
- 🎴 **Карточки игроков** (PNG через Pillow + текстовый вариант)
- 🏆 **Мемные ачивки** — Замуж за сферу, Шавермоверум, Веторио в шоке и др.
- 📖 **Хроника матча** в конце игры
- 🎯 **Инлайн-кнопки** для действий: тык → выбор цели → действие
- ✍️ **РП-текст с тегом** `#темпал` — игроки описывают ход в чате, бот ловит
- 💾 **Сохранение состояния** в JSON — переживает рестарт
- ⏸ **Пауза/возобновление** доступны только владельцу группы или создателю лобби

## Запуск локально

```bash
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# впиши свой токен от @BotFather в .env
python -m tempal.main
```

## Деплой на Railway

1. Создай новый проект из этого репозитория.
2. В `Variables` добавь `TELEGRAM_BOT_TOKEN`.
3. Railway сам прочитает `Procfile` и запустит `worker`.

## Деплой на Render

1. Создай **Background Worker** (не Web Service — у бота нет HTTP-эндпоинта).
2. Build: `pip install -r requirements.txt`
3. Start: `python -m tempal.main`
4. Env: `TELEGRAM_BOT_TOKEN`.

## Команды бота

| Команда | Где | Что делает |
| --- | --- | --- |
| `/newgame` | в группе | открыть лобби |
| `/join` `/leave` | в группе | войти/выйти |
| `/myteam A` или `B` | в группе | вручную выбрать команду |
| `/startgame` | в группе | стартовать матч (минимум 2+2 игрока, только создатель лобби) |
| `/act` | где угодно | открыть меню действий в свой ход |
| `/status` | в группе | состояние арены и счёт |
| `/score` | в группе | счёт |
| `/card` (или ответом на чьё-то сообщение) | в группе | темпоральный паспорт игрока |
| `/pause` `/resume` | в группе | пауза/продолжение (владелец группы) |
| `/endgame` | в группе | завершить матч + хроника |

## Картинки арен

Бросай PNG/JPG в папку `arenas/`. Бот выбирает их случайно для раундов
(в текущей версии бот рисует эмодзи-карту — реальные картинки арен
подключатся в одной из ближайших итераций).

## Структура

```
tempal/
├── config.py             # настройки и env
├── main.py               # точка входа aiogram
├── middleware.py
├── game/                 # чистая логика игры
│   ├── abilities.py      # 4 способности из лора
│   ├── achievements.py   # мемные ачивки
│   ├── models.py
│   ├── resolver.py       # разрешение раунда
│   ├── rolls.py          # d20 + распределение способностей
│   ├── storage.py        # JSON-снапшот
│   └── zones.py
├── services/             # обёртки над telegram / отображение
│   ├── arena_map.py
│   ├── cards.py          # PNG-карточки игроков
│   ├── chaos.py
│   ├── chronicle.py
│   └── dice.py           # кинематографичные роллы
└── handlers/             # aiogram-роутеры
    ├── admin.py          # /pause /resume /endgame
    ├── common.py
    ├── gameplay.py       # игровой цикл
    ├── info.py           # /status /score /card
    ├── keyboards.py
    └── lobby.py          # /newgame /join /startgame
```
