# Arenas

Drop arena background images (PNG/JPG) here. The bot picks one randomly at the
start of each match and shows it as a photo when the match begins. The visual
arena is purely cosmetic — zones (acceleration / slowdown / normal / inversion
/ chaos) are determined separately at random each round per the lore.

Recommended size: 1024×1024 PNG, square aspect ratio.
